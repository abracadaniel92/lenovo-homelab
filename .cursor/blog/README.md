# Blog candidates

Stories from homelab work that might become posts on gmojsoski.com. Written by the
blog-capture rule (`../rules/blog-capture.mdc`) when work finishes, reviewed weekly with
the `blog-review` skill. The posts themselves live in the `portfolio_v2` repo.

- `_TEMPLATE.md`: shape of a candidate.
- `pending/`: waiting for review. `YYYY-MM-DD-<slug>.md`.
- `approved/`: worth writing, with outline, effort and priority.
- `published/`: written and live, with the URL.
- `rejected/`: turned down; the reason is in `decisions.md`.
- `decisions.md`: one row per decision, so rejected ideas don't come back without new evidence.
