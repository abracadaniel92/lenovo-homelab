# Lesson proposal template

Copy this structure into every file under `pending/`. One lesson per file. No secrets, URLs
with tokens, internal IPs or personal detail: this repo is public, see
`../rules/lesson-capture.mdc`.

**Proposed change:** The exact edit: which file, which line or section, what it should say
instead.

**Why now:** What happened in this session that surfaced the gap. One or two sentences.

**Evidence:** Date, and what was observed: what was tried, what failed or was slow, what the
user said. Specific enough that `lesson-review` can judge it without re-reading the whole
session.

**Scope:** The one file this touches. If it looks like it should touch more than one file,
write more than one proposal instead.

**Boundaries:** What this change does NOT do, so the edit stays small when it's applied.
