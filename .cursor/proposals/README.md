# Lesson proposals

Written by the lesson-capture rule (`../rules/lesson-capture.mdc`) during normal work, and
reviewed one at a time by the `lesson-review` skill, usually weekly. Nothing in here is ever
applied to a skill, rule, `CLAUDE.md` or the service checklist without the user approving it
first.

- **`_TEMPLATE.md`**: the five-bullet structure every proposal uses.
- **`decisions.md`**: one-line log of every decision, applied or rejected, so a rejected idea
  isn't proposed again without new evidence.
- **`pending/`**: proposals waiting for review. Filename: `YYYY-MM-DD-<short-name>.md`.
- **`applied/`**: approved proposals whose edit has been made. Kept as a record of what
  changed and why.
- **`rejected/`**: proposals the user turned down, with the reason in `decisions.md`.

Only lessons about *how the agent works in this repo* belong here. Facts about the homelab
(incidents, config changes) go to the device's troubleshooting log.
